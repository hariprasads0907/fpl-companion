# My agent: fpl-scout
One-liner: A conversational agent that helps Fantasy Premier League (fantasy.premierleague.com) managers optimize their squad, captaincy picks, transfers, and track mini-league standings with live Premier League data.

Tool coverage:
- Memory: Remembers the user's FPL team ID, favorite clubs, budget constraints, target transfer watchlists, and chip usage history
- Tools: Live FPL API integration fetching manager profile, mini-league standings, player form/prices/xG/xA stats, team fixtures, and FDR ratings
- Catalog/UI: Premier League player catalog, upcoming fixture schedules, and mini-league leaderboards rendered as structured cards and tables
- Image gen: Infographics, pitch formation diagrams, captaincy comparison cards, and player radar charts
- Sandbox: Transfer optimization calculations, expected points (xP) modeling, and budget scenario simulations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: live official FPL public APIs, code sandbox for transfer optimization calculations, Cloud Trace observability
